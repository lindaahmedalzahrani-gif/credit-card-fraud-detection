# 💳 Credit Card Fraud Detection

A machine learning project for detecting fraudulent financial transactions using data preprocessing, feature engineering, class balancing, and multiple classification algorithms.

## Project Overview

The project analyzes transaction, customer, merchant, and fraud-related data to build machine learning models capable of classifying transactions as fraudulent or legitimate.

## Data Preparation

The preprocessing pipeline includes:

- Merging multiple transaction-related datasets
- Data cleaning and preprocessing
- Handling categorical features
- Feature engineering
- Feature scaling
- Analyzing class imbalance
- Oversampling
- Train/test splitting

## Machine Learning Models

Several classification algorithms were implemented and compared:

- Random Forest
- Logistic Regression
- XGBoost
- Decision Tree

Hyperparameter tuning was performed to improve model performance.

## Evaluation

Models were evaluated using classification metrics including:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix
